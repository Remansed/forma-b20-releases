# Форма Б20 — загрузки и обновления

Публичный репозиторий для готовых сборок и метаданных обновления приложения «Форма Б20» для ReMad.

## Состояние

Готовые версии пока не опубликованы. После подготовки сборок они появятся в разделе [Releases](https://github.com/Remansed/forma-b20-releases/releases).

Исходный код приложения хранится отдельно и не публикуется в этом репозитории. Здесь не размещаются игровые HAR, данные аккаунтов, ключи лицензий или административные инструменты.
